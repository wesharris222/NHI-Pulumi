# Reference Documentation

This directory holds supplementary reference material that doesn't fit cleanly into PROGRESS, README, ARCHITECTURE, or TALK_TRACK.

## Suggested files to add as the project develops

- `saviynt-api-reference.md` — confirmed endpoint paths, request/response shapes, quirks discovered during build
- `troubleshooting.md` — common failure modes and how to diagnose
- `demo-script.md` — minute-by-minute demo walkthrough with screen-by-screen narration
- `extension-ideas.md` — workflows from the original planning that didn't make v1 (NHI certification campaigns, drift-triggered break-glass, ESC Connect integration, etc.)

These are optional. Only create them when you need them.
